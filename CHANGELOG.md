# Changelog

## [Unreleased]

### Added

- **Live `/qa` agency hold review** — in-app page (TopBar **QA** · `http://localhost:5174/qa` with `just editor`) exports the same canonical-agency shell as `npm run qa:dco`, serves it at `/qa-shell/`, and shows settled holds as a spritesheet-style grid via shared `agency-timeline-seek` (no Playwright/PNGs). Editor-style top bar: Size + Offers/T&Cs/CTA/Frame/Copy segmenteds, thumbnail zoom; rail has copy fields + collapsible size monitor. See `docs/QA_DCO_MATRIX.md`.
- **QA hold-samples.json** — `npm run qa:dco` derives settled review timestamps from creative JSON clip plateaus (`src/lib/hold-samples.ts` → `compileAnimationClips` / `frameAtPercent`), per session × size, snapped to the 250ms capture grid. Regenerate with `npm run qa:dco:holds -- --output qa-output/<run>`. The dco-qa-review skill reads this list instead of hardcoded `t4000`/`t7000`/….
- **QA settled/ scan sheets** — each run also writes `settled/{size}/{sessionId}.png` spritesheets containing **only** derived hold frames (grouped by size for scanning). Rebuild with `npm run qa:dco:settled -- --output qa-output/<run>`.
- **DCO visual QA matrix** — local Playwright pipeline (`npm run qa:dco`) exports canonical-agency HTML into `.qa-work/`, injects **12** stress feed rows (6 layout variants × `short`/`long`) across all sizes, captures the 15s timeline at **4 fps** with **1 fps** spritesheets under `qa-output/<YYYYMMDD-HHMMSS>/`, plus a deduped on-stage DOM flag report. Capture uses a page pool (`--concurrency` / `-j`). Visual review via Cursor skill `.cursor/skills/dco-qa-review`. See `docs/QA_DCO_MATRIX.md`.

### Fixed

- **offers-0 CTA independence** — brand CTAs use compound scopes `offers-0.cta-rect` / `offers-0.cta-roundel` (full geometry + colour each), so Rect/Round no longer share position or size with each other or with offers 1–3. Legacy `offers-0|cta` migrates on load/save.
- **Offer decimals crushing gap/plus layout** — `layoutOffers` glyph-ink digit filter lived in a template-literal source string where `\d` / `\s` cooked away, so the inlined runtime ran `/[^d.]/g` and measured a lone `.` for values like `1.5` / `10.5`. That collapsed cluster height, packed vertical offers together, and parked the plus on the decimal. Escapes are doubled; value runs now sample digits only.
- **Sample preview live update** — the stage now re-renders as you type Sample values. Preview was subscribing to the stable `selectedFeedRow` helper instead of the feed row itself, so copy only refreshed when something else (e.g. the timeline) forced a paint. The row selector uses a frozen empty fallback so an unloaded feed cannot return a new `{}` each read (that had crashed Sample with “Maximum update depth exceeded”).
- **Sample inspector focus loss** — editing Sample feed fields no longer clears a non-offer selection (roundel, headline, CTA, …). `reconcileOfferSelection` only prunes inactive offer-block members, so typing values keeps the Sample section and inspector open.
- **Single-line text-fit false shrink** — shrink with `maxLines` ≤ 1 (nowrap) no longer treats tall Museo Range ink as a line-budget overflow, which had driven roundel copy/value to `minFontSize` and clamped content `maxHeight` below the authored box. Single-line shrink is width-only; multi-line wrap budgets are unchanged. Shared engine — editor and export stay in lockstep.

- **Export for Static package layout** — download zips (`{slug}_html_static.zip` and Sync Zips’ `SSE_Statics_*.zip`) now nest `campaigns/{slug}_{size}.zip` units; each unit is that size’s HTML plus `assets/<basename>.jpg` for that size only. Pages `/statics/` still uses the loose `outputs/campaigns/<id>/` tree for iframe preview.
- **Docs sync** — refreshed `docs/` (API, architecture, workflow, feed schema/fields) and `AGENTS.md` / `README.md` against current registry, Sync Zips/`outputs/`, outline bake, export menu labels, sample-row defaults, static `clickTag`s, and Museo-only packaging.
